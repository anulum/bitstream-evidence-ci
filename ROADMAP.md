# Roadmap

## Current foundation

Repository identity, legal texts, architecture, governance, native documentation and dedicated validation tools are being qualified. Domain capabilities and claims remain empty.

## Capability milestones

Complete source/toolchain pin admission precedes the first version-specific Libero adapter and bounded actual attempt capture. Exact raw report interpretation and independently reproduced gates precede actual rebuild comparison and trusted immutable build history. All seven public operations then need complete receipts, real installed provider and producer/consumer qualification, parity and recovery evidence.

Later vendor adapters and optional anchoring remain conditional extensions. Actual package installation, external reproduction, hosted automation and any release require their own completed lifecycle evidence. No dates, product availability or performance outcomes are promised.
